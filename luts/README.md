# LUTs

`soft-pastel-cinematic.cube` (full) and `soft-pastel-cinematic-subtle.cube` (60%), generated by `make-soft-pastel-lut.py`
(33^3, Rec.709). Apply before composing: `ffmpeg -i in.mp4 -vf "lut3d=file=luts/soft-pastel-cinematic-subtle.cube:interp=tetrahedral" out.mp4`.

**Status: parked.** Not part of the default pipeline and not applied to any video yet. The owner chose to perfect the foundation
first. Do not apply a LUT unless the user asks. Tested on real frames: skin tones stay natural; the effect is gentle on bright footage.
