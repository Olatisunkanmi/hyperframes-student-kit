# LUTs

`soft-pastel-cinematic.cube` (full) and `soft-pastel-cinematic-subtle.cube` (60%), generated by `make-soft-pastel-lut.py`
(33^3, Rec.709). Apply before composing: `ffmpeg -i in.mp4 -vf "lut3d=file=luts/soft-pastel-cinematic-subtle.cube:interp=tetrahedral" out.mp4`.

**Status: in use by the studio pipeline's grade step** (`scripts/grade-clean.mjs`, first used on img-9354 at the owner's request). Always
open its `--preview` before applying. Tested on real frames: skin tones stay natural; the effect is gentle on bright footage.

The default grade for the studio pipeline is applied with `node scripts/grade-clean.mjs <project>` (it uses the subtle LUT, a cooler white
balance and a touch of contrast; open its `--preview` first). It writes `assets/clean-graded.mp4` for that project only.
